# Default Notes Location in Obsidian

Obsidian lets you choose where newly created notes are saved by default.

Settings → Files & Links → Default location for new notes
## How to configure

1. Open **Settings**:
- Click on the ⚙️ **Settings** icon in the bottom left
- or Press `Cmd + ,` on macOS

1. Go to **Files and Links** section in the settings

2. Find **Default location for new notes**

	### Default Location for new notes

- **Vault folder** - to save new notes in root vault folder
- **Same folder as current file** - to save notes in which the current opened notes is saved
- **In the folder specified below** - to save notes in the folder mention in the below selection "Folder to create a new notes in"
