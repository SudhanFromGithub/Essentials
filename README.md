# Essentials 🚀

**A personal productivity toolkit with scripts, formulas, and automation hacks for power users and professionals.**

---

## 📦 Overview

Essentials is a curated repository of useful AutoHotkey scripts, Excel formulae, VBA macros, financial trackers, and inspirational quotes. Designed for Chartered Accountants, automation enthusiasts, and tech-savvy professionals, it simplifies everyday workflow with ready-to-use resources.[](https://www.hatica.io/blog/best-practices-for-github-readme/)​

---

## 🗂️ Directory Structure

| Folder                   | Description                                            |
| ------------------------ | ------------------------------------------------------ |
| **ahk-scripts**          | AutoHotkey (.ahk) scripts for Windows automation       |
| **books**                | Personal reading and reference lists                   |
| **credit-card-expenses** | Track and analyze your spending                        |
| **Excels**               | Sample Excel files and problem solvers                 |
| **Formulae**             | Common and advanced Excel formulas for data management |
| **quotes**               | Quotes for motivation and creativity                   |
| **VBA**                  | Practical VBA macros to automate Excel workflows       |

## 💡 Features

- Instantly increase Windows productivity with custom ahk-scripts.[](https://www.freecodecamp.org/news/how-to-write-a-good-readme-file/)​

## 🚀 Getting Started

1. **Clone this repository:**
    
>[!important] cli
>```
>git clone https://github.com/SudhanFromGithub/Essentials.git`
>```

    
2. **Explore the folders:** Find the script, macro, or formula you need.
    
3. **Customize code:** Edit scripts and Excel files to match your workflow.
    
4. **Run AutoHotkey scripts:** Install [AutoHotkey](https://www.autohotkey.com/) and double-click `.ahk` files.
    
5. **Use VBA macros:** Copy and paste VBA codes into your Excel VBA editor.
